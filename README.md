File Descriptions
1. Jupyter Notebook (.ipynb)Description: An interactive Python notebook focused on JSON serialization and deserialization tasks using the built-in json module. 
Contents:json.dumps(): Demonstrates how to serialize Python dictionaries into JSON formatted strings (with examples mapping name, age, and compound attributes). 
json.loads(): Demonstrates parsing/deserializing JSON strings back into native Python dictionary objects

2. data 6.jsonDescription: A raw or uncleaned JSON data file representing a similar user-page interaction network, featuring raw attributes and edge cases.   
Contents:Users: Includes users with varied data states, such as missing names, empty friend/liked page lists, and duplicate entries.   
Pages: Includes community page entries, featuring duplicate ID definitions (e.g., ID 104 mapped to both "Web Dev Hub" and "Web Development").


3. cleaned_codebook_data.jsonDescription: A structured and curated JSON file containing pre-processed social network style records.   
Contents:Users: Lists specific user profiles, their unique IDs, friend connections, and liked page references (e.g., Amit, Priya, and Sara). 
Pages: Contains information on community pages with their respective IDs and titles (e.g., Python Developers, Data Science Enthusiasts, AI & ML Community, and Web Development).
